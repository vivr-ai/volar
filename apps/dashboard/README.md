# @volar/dashboard

Next.js (App Router) + TypeScript + Tailwind customer-facing dashboard app.
Scaffolded in Engineering Execution Plan issue 1.2. See the repo root
README for workspace-wide setup.

## Local development

```bash
# from repo root
pnpm install
pnpm --filter @volar/dashboard dev
```

Currently a placeholder home page only. Real screens are built starting
with Epic 11 (App Shell & Navigation) and Epic 12 (Onboarding/Install).
